# 19.0.1.11.0 — Embedded composer controls

- Place attachment, emoji, audio recording and Send controls inside one message box. Mirror placement in RTL and center the localized “Write a message...” placeholder.
- Add a hover/click attachment menu with Photo/video, Location, Document, Music and saved templates. Keyboard Escape and outside click dismiss it; channel changes close it. File selection cannot attach to a different conversation after navigation.
- Location inserts a validated coordinate map link into the current draft for explicit review and sending. It never sends automatically.
- Support outgoing MP4 video through the existing private attachment and queue workflow, capped at 16 MB. Keep private preview/download, immutable history and server authorization. Existing optional WhatsApp video selection ownership remains intact.
- Put the conversation-search guidance inside the search input as a localized, accessible placeholder.
- Update both Arabic catalogs and validate desktop/mobile English, ar and ar_001. See VALIDATION.md for evidence and deployment limits.
