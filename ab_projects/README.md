# Abdin Development Projects

`ab_projects` extends native Odoo Projects for software and development teams.

The module keeps Odoo's existing project, task, milestone, dependency,
timesheet, activity, and chatter behavior, then adds a focused development
layer:

- Project type, health, technical lead, and project links.
- Task type, story points, sprint, release, reviewer, QA, branch, pull request,
  blocked status, and lightweight bug details.
- Simple sprints and releases connected directly to `project.task`.
- Project dashboard, My Work, team visibility, and practical reports.

No Odoo core files or native `project` module files are modified.
