## ١. تغييرات الواجهة في الموديولات المثبتة

| الوصف | هل تحتاج ترقية؟ |
| ---: |---:|
| **المبيعات:** إضافة إمكانية تصفية الأصناف بين «الكل / أدوية / غير أدوية» أثناء البحث، سواء في نقطة البيع أو عند البحث عن الفواتير. كما تم تحسين ترتيب خيارات البحث وإضافة بعض التوضيحات والترجمات العربية. |         **نعم** |
| **روشتات الأطباء:** إضافة إمكانية البحث عن الفواتير باستخدام طبيب واحد أو أكثر، مع إمكانية تصفية أصناف الروشتة بين الأدوية وغير الأدوية. |    **موصى بها** |
| **فواتير التعاقدات:** إضافة عمود «الإجمالي بعد الخصم» لتسهيل مقارنة إجمالي الفاتورة بقيمتها الفعلية بعد الخصومات. |         **نعم** |
| **قائمة الفواتير:** إضافة اسم التعاقد إلى قائمة الفواتير لتمييز فواتير التعاقدات بسهولة دون الحاجة إلى فتح كل فاتورة. |         **نعم** |
| **تفاصيل الفاتورة:** إظهار اسم موظف المبيعات ونوع الفاتورة، مثل التعاقد أو العرض أو التوصيل، لتسهيل معرفة طبيعة الفاتورة من شاشة البحث. |         **نعم** |
| **الشريط الجانبي لنقطة البيع:** إضافة زر «إزالة الكل» لإغلاق جميع الفواتير المفتوحة من مساحة العمل دفعة واحدة، دون التأثير على الفواتير التي تم حفظها بالفعل. |         **نعم** |


## ٢. الموديولات الجديدة والغرض منها

| الوصف |
| -: |
| **متابعة التوصيل عبر تيليجرام:** إرسال بيانات طلب التوصيل إلى مجموعة المتابعة على تيليجرام، مع إمكانية تسجيل استلام الطلب من خلال زر «تم الاستلام». **يُفعل عند بدء تطبيق نظام متابعة التوصيل الجديد.** |
| **رفع بيانات المبيعات إلى التقارير:** تجهيز ونقل بيانات المبيعات والمرتجعات والروشتات والتحويلات والطلبات وغيرها إلى منظومة التقارير، مع الفصل بين البيانات الحالية والبيانات التاريخية. **يُفعل عند تشغيل منظومة التقارير الجديدة.** |
| **هويات المستخدمين المرجعية:** توفير بيانات تعريف مختصرة للمستخدمين بهدف ربطهم ببيانات التقارير والمزامنة دون الحاجة إلى إنشاء حساب استخدام كامل لكل شخص. **يُستخدم كجزء من منظومة التقارير والربط بين الأنظمة.** |
| **ربط الفرع بالكول سنتر:** تمكين الكول سنتر من البحث عن الأصناف والأرصدة، وإرسال المبيعات والمرتجعات، ومتابعة نتائج العمليات الخاصة بالفروع المسموح بها. **يُفعل عند بدء تكامل الكول سنتر مع الفروع.** |


## ٣. تحديثات في الموديولات المثبتة دون تغيير الواجهة

| الوصف |
| -: |
| **استيراد برامج العروض:** إضافة بيانات جديدة مطلوبة داخل ملف استيراد العروض، تتعلق بطريقة التعويض ونوعه وملكية العرض، بهدف تحسين دقة تسجيل بيانات برامج العروض. |
| **إجمالي فاتورة التعاقد:** تحسين طريقة حساب إجمالي فاتورة التعاقد قبل الخصم، مع الحفاظ على صافي المبلغ المطلوب من العميل وفق قيمة تحمله. |
| **إجماليات المبيعات:** تصحيح طريقة احتساب إجمالي المبيعات ليعبر بصورة أدق عن قيمة الأصناف قبل الخصومات. |
