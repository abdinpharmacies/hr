# Codex workflow conventions

These are reusable preferences for plain Codex and every workflow profile. Follow the user's
current request and explicit project requirements when they differ. Read the
working project's applicable AGENTS.md files before editing.

Use available skills only when relevant. A skill's availability does not grant
permission to deploy, publish, rewrite history, or send messages. Respect prior
authorization; do not repeat questions already answered.

Use the tools actually exposed by the current Codex session. Imported MCP tool
names describe capabilities, not guaranteed integrations. Use local CLI tools
when appropriate and report missing capabilities without inventing tool calls.

Custom agents are specialists, not profiles. Delegate when the user or an
applicable project or skill instruction calls for it. Keep the active profile's
scope when choosing a specialist. Inherit the selected model unless the user
requests a different one.
