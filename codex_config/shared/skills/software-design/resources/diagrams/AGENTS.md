# Diagram resource instructions

This folder contains optional rendering resources for the unified software-design skill. Read ../../references/diagrams.md before selecting a renderer. This folder is not a separately discoverable skill.

Use the installed project renderer or the matching local toolchain. Do not run npm ci, bootstrap or gallery scripts by default. Package installation requires authorization. Inspect scripts before use; gallery runs cover examples only, not user diagrams. Preserve editable sources and inspect rendered images before claiming readability.

The legacy GUIDE.md and format references document tool mechanics; the unified skill controls scope and deliverables.
