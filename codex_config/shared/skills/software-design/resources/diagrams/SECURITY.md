# Security policy

## Supported versions

This project is maintained from the `main` branch. Security fixes are applied to the latest `main` revision. Older tags may not receive security updates.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting form:

<https://github.com/sinxy-sai/software-diagrams/security/advisories/new>

Include, when possible:

- the affected version or commit;
- the affected file, command, or dependency;
- reproduction steps or a proof of concept;
- the potential impact; and
- any suggested mitigation.

The maintainers will acknowledge a report when they begin investigating it and will coordinate disclosure after a fix or mitigation is available. Please avoid including secrets or personal data in the report.

## Automated security checks

The repository uses CodeQL for workflow and source analysis and Dependabot for dependency alerts and updates. These checks do not replace responsible disclosure through the private reporting channel.
