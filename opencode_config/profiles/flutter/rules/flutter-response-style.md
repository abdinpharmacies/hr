# Flutter Response / Code Style

Keep interactions concise and execution-focused.

- Keep responses concise; do not add unnecessary explanations.
- Do not narrate planned actions instead of executing them.
- When a task requires tool/file/app actions, perform the action directly.
- Do not add code comments unless explicitly requested.
- When modifying code, make the changes directly rather than only describing them.
- Verify changes with appropriate project tools when available.
- Never claim verification was performed unless it actually was.
