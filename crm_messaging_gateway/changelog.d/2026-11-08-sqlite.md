# SQLite transport and queued WhatsApp payloads

Current changes before commit:
- Gateway version 1.1.0 retains PostgreSQL and adds a patched, gateway-only APSW SQLite runtime with WAL, FULL synchronization, short transactions, atomic polling offsets, local receiver locks and bounded contention.
- Adds bounded export/import with counts/digests, consistent hourly-backup unit templates, restore tests and a process-based synthetic capacity harness. No pruning or live cutover.
- Adds outgoing-only WhatsApp configuration, template/media/reaction payloads, terminal authorization rejection and sanitized latency/backlog/lock/disk metrics.
- Preserves the independent API, receiver and worker processes. SQLite requires no queue PostgreSQL connection or credentials.
